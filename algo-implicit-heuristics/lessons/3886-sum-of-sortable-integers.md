# 示例课 03：唯一目标与断点（模块 D，层级 B，成文模式）

> 题目：LeetCode 3886. Sum of Sortable Integers / 可排序整数求和（Hard，n ≤ 10⁵）

**题目背景**：给你一个长度为 n 的整数数组 nums。整数 k 称为"可排序整数"，当且仅当 k 是 n 的因数，且把 nums 划分成长度为 k 的连续子数组、每块独立循环移位任意次后，整个数组变成非递减。返回所有可排序整数 k 的和。

**为什么不落模块 A（状态映射与环）**：模块 A 的表述模式是"每个元素有当前位置和目标位置"，3886 字面上确实落进去，但它给的是**错误的直觉**。以 `nums = [2, 1, 4, 3]`（目标 `[1, 2, 3, 4]`）为例，位置置换是 `2→1, 1→0, 4→3, 3→2`，即 `(0 1)(2 3)`，两个 2-环：

- k = 2：每块一次 2-循环，块的转恰好就是 `(0 1)` 与 `(2 3)` → **可行**；
- k = 4：整串的转是一个 4-循环，产生的置换是 `(0 2)(1 3)` 一类，产生不出两个 2-环 → **不可行**。

同一个置换，模块 A 的"环结构"给不出任何区分。可行性取决于"所需置换是不是整块转的幂"，这与"最少交换几次"是两个问题。因此按 3.1 的准入流程现场声明**模块 D**，不扩模块 A 的边界参数（扩了反而会把一个失效的框架固化进去）。

**模块 D 六字段声明**（现场声明，轻量，不落库；回扣实体与不覆盖的问题一并写全）：

| 字段 | 内容 |

| 问题表述模式 | 操作被限制在"按固定长度切出的连续块"内部，块内操作是一个有限循环（循环移位），而目标是被唯一确定的那一个排列（整串排好序后的样子）；问的是可达性，不是最少次数 |
| 核心术语 | 唯一目标、断点、单调环 |
| 核心动词 | 转到、对齐 |
| 边界参数 | 目标：整串非递减 → 每块内部非递减；块内操作：循环移位 → 块内任意重排；元素：互不相同 → 存在重复值；块划分：n 的等分因数 → 任意指定边界 |

## 二、课文

数组 [2, 1, 4, 3]，长度 4。取 k = 2，沿原顺序切成两块：[2, 1] 和 [4, 3]。第一块往右转到 [1, 2]，第二块往左转到 [3, 4]；边界一动不动，四个数落进 [1, 2, 3, 4]。这就是它们该对齐的那一串——不是随便哪种排好的样子，而是这四个数排好序之后必然长成的那一个。

换成 [3, 1, 4, 2]，同样只准把每块转到自己的位置上。目标定成整串非递减时：k = 1 的话单元素转到原地，3 落不到 1 那一格；k = 2 的话 [3, 1] 无论转到哪一位都是 3 和 1，而它该对齐的是 [1, 2]；k = 4 的话 [3, 1, 4, 2] 转到哪一位都不排好序。三个 k 全部落空，能算数的 k 一个没有，和是 0。目标换成每块内部非递减：k = 1 天然满足，k = 2 的两块分别转到 [1, 3] 和 [2, 4]，k = 4 整串转到哪一位都不排好序，和是 1 + 2 = 3。同一组数，同样的转法，目标是整串还是各块，答案是 0 还是 3。

整串非递减这句话把目标钉死了：不管选哪个 k，能接受的落地结果只有一串——整个 nums 排好序之后的那一串。它有一个名字：唯一目标。块与块之间不搬家，块内又是转到停不下来的循环，所以每块能落到的位置也就有限。把一块首尾相接看成一个圈，从任意一处读起，读到某个位置数值掉下去——掉下去的那处叫断点。绕一圈只掉一次、掉下去以后接上的正好是它该对齐的那块，这样的圈叫单调环。判据于是缩成一句：每块自己成一个圈，绕一圈只断一次，断口对上的正是它该对齐的那一块。

把元素换成有重复值的：[1, 2, 1]。首尾相接读一圈，2 掉到 1 的地方掉了一次；从掉下去的地方切开，剩下 [1, 1, 2]。同样的数换一种摆法，[2, 1, 1] 也是 [1, 1, 2] 转出来的，断点的位置不再只有一个，可它照样只断一次。而 [1, 2, 1, 2] 读一圈要掉两次（2→1 落在第 1 位和第 3 位），转到哪一步也回不到排好序的样子。重复值不改变判据，只让"选哪一个断点"变得无所谓；真正要数的是断点的个数。

回到 [2, 1, 4, 3] 这串：k = 2 时两块各自成圈，[2, 1] 绕一圈掉一次（2→1），从断点切开是 [1, 2]，正好对齐到它该去的那块；[4, 3] 同样只掉一次，切开是 [3, 4]。两块都对齐得上，k = 2 算数。k = 4 时整串成一个圈，掉下去三处（2→1、4→3、3→2），断点不止一个，对齐不上那个唯一目标，k = 4 不算。k = 1 时每块只剩一个数，转到哪一步都在原地，首位的 2 落不到 1 上，也不算。三条因数里只有 2 算数，和就是 2。
换成 [3, 4, 1, 2] 这串长度 4 的数组，同样把能算数的 k 列出来。

## 三、结论与实现

> 以下是读者完成末尾微变体后的对照材料。

### 判据（课文的可执行形式）

设 `s = sorted(nums)`。k 可排序 ⟺ 对每个长度为 k 的块 `A = nums[st:st+k]`：

1. **唯一目标对齐**：`A` 转出来的结果必须**逐位等于** `s` 的同一段 `s[st:st+k]`。注意目标块由**全局**排序决定，不是"这块自己排好序"——这是本模块的边界参数，也是最常见的错解。
2. **单调环**：`A` 首尾相接读一圈，**环形下降点（断点）恰好 1 个**（k = 1 时为 0 个）。断点唯一 ⟺ `A` 是某个升序序列的循环移位。

两个条件合起来等价于一条：**`A` 是 `s` 对应块的循环移位**。第 1 条已经蕴含了"块内多重集相等"，不需要单独判多重集。

### 为什么"数断点"等价于"能转过去"

一块长 k 的循环移位，在位置上是一个 k-循环，它生成的置换是它的幂（恒等、或某个完整的 k-循环）。因此"存在一种转法把 `A` 变成目标块"⟺"所需置换是 k-循环的幂"⟺"把 `A` 读成圈时只断一次"。这正是第 3 段那个"绕一圈只断一次"的来源。

### C++ 实现

```cpp
class Solution {
public:
    int sortableIntegers(vector<int>& nums) {
        int n = (int)nums.size();
        vector<int> s = nums;
        sort(s.begin(), s.end());
        long long ans = 0;
        for (int k = 1; 1LL * k * k <= n; ++k) {
            if (n % k) continue;
            if (alignable(nums, s, k)) ans += k;
            int k2 = n / k;
            if (k2 != k && alignable(nums, s, k2)) ans += k2;
        }
        return (int)ans;
    }

private:
    // 每块自己成一个圈：断点恰好一个，且从断点切开正好是目标块
    bool alignable(const vector<int>& nums, const vector<int>& s, int k) {
        int n = (int)nums.size();
        for (int st = 0; st < n; st += k) {
            int brk = -1;
            for (int i = 0; i < k; ++i) {
                if (nums[st + i] > nums[st + (i + 1) % k]) {   // 环形下降点
                    if (brk != -1) return false;              // 断点超过一个
                    brk = i;
                }
            }
            int off = (brk == -1) ? 0 : brk + 1;              // 从断口之后开始读
            for (int i = 0; i < k; ++i) {
                if (nums[st + (off + i) % k] != s[st + i]) return false;  // 对齐唯一目标
            }
        }
        return true;
    }
};
```

**复杂度**：枚举 n 的因数 O(√n)，每个因数校验 O(n) → O(n log n + n·d(n))，其中 d(n) 为因数个数（n ≤ 10⁵ 时 d(n) ≤ 128），空间 O(n)。
